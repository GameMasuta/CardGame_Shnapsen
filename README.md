# シュナプセン

PC・スマートフォンのブラウザで動く、対CPU専用のシュナプセン実装です。ブラウザで開くだけで遊べます。

## 特徴

- 2人用カードゲーム「シュナプセン」のローカルWebアプリ
- 対CPU戦
- CPU難易度 3段階
- マリッジ、切札J交換、クローズ、66点宣言に対応
- 7ゲームポイント先取
- カード移動アニメーションと得点ダイアログ付き

## 起動方法

1. `index.html` をブラウザで開きます。
2. 難易度を `Easy / Normal / Difficult` から選びます。
3. `新しい試合を開始` を押してプレイします。

必要なら簡易サーバーでも起動できます。

```bash
cd schnapsen
python3 -m http.server 8000
```

その場合は `http://localhost:8000` を開いてください。

## テスト

## スマートフォンでの操作・確認

- 画面幅600px以下では手札5枚を横一列、得点と盤面を2列に表示します。
- 出せる手札をタップするとプレイします。カードの「+20」「+40」はマリッジ宣言の得点です。
- 切札交換・クローズ・66点宣言は盤面下のボタンをタップします。
- 得点ダイアログはタップで閉じられます。PCではSpace・Enterも使えます。
- ダークモードは画面上部のスイッチで変更できます。

実機確認はPCとスマートフォンを同じWi-Fiへ接続し、上記の簡易サーバーを起動して、
スマートフォンのブラウザで `http://<PCのLAN IPアドレス>:8000` を開きます。
接続できない場合はPCのファイアウォールとWi-Fiの端末間通信設定を確認してください。

確認対象：幅320・375・390・430px、横向き、PC表示、通常／ダークモード、
手札のタップ、カード移動、得点ダイアログ、次ディールへの進行。
今回の変更はモバイル画面の調整です。PWAインストール・オフライン対応はまだ含みません。


### モバイル画面の改善

「ゲーム設定」を開くと難易度・ダークモード・新しい試合を操作できます。
ゲームログと実装ルールも見出しをタップして展開します。
スマートフォンではタイトルとCPU手札を省スペース化し、盤面と自分の手札を近づけています。
小さい画面や文字を拡大した場合は縦スクロールで操作できます。
ダークモードではログ背景も暗色に切り替わります。
人間が先手の待機中はCPU処理を開始せず、誤った停止ログを出さないようにしています。
