# シュナプセン

PC・スマートフォンのブラウザで動く、対CPU専用のシュナプセン実装です。ブラウザで開くだけで遊べます。

## 特徴

- 2人用カードゲーム「シュナプセン」のローカルWebアプリ
- 対CPU戦
- CPU難易度 3段階
- マリッジ、切札J交換、クローズ、66点宣言に対応
- 7ゲームポイント先取
- カード移動アニメーションと得点ダイアログ付き

## 起動方法

1. `index.html` をブラウザで開きます。
2. 難易度を `Easy / Normal / Difficult` から選びます。
3. `新しい試合を開始` を押してプレイします。

必要なら簡易サーバーでも起動できます。

```bash
cd schnapsen
python3 -m http.server 8000
```

その場合は `http://localhost:8000` を開いてください。

## テスト

ロジック確認用の簡易テストを追加しています。

```bash
cd schnapsen
node test.js
```

## スマートフォンでの操作・確認

- 画面幅600px以下では手札5枚を横一列、得点と盤面を2列に表示します。
- 出せる手札をタップするとプレイします。カードの「+20」「+40」はマリッジ宣言の得点です。
- 切札交換・クローズ・66点宣言は盤面下のボタンをタップします。
- 得点ダイアログはタップで閉じられます。PCではSpace・Enterも使えます。
- ダークモードは画面上部のスイッチで変更できます。

実機確認はPCとスマートフォンを同じWi-Fiへ接続し、上記の簡易サーバーを起動して、
スマートフォンのブラウザで `http://<PCのLAN IPアドレス>:8000` を開きます。
接続できない場合はPCのファイアウォールとWi-Fiの端末間通信設定を確認してください。

確認対象：幅320・375・390・430px、横向き、PC表示、通常／ダークモード、
手札のタップ、カード移動、得点ダイアログ、次ディールへの進行。
ホーム画面追加用のPWA設定を含みます。オフライン対応は未実装です。


### モバイル画面の改善

「ゲーム設定」を開くと難易度・ダークモード・新しい試合を操作できます。
ゲームログと実装ルールも見出しをタップして展開します。
スマートフォンではタイトルとCPU手札を省スペース化し、盤面と自分の手札を近づけています。
小さい画面や文字を拡大した場合は縦スクロールで操作できます。
ダークモードではログ背景も暗色に切り替わります。
人間が先手の待機中はCPU処理を開始せず、誤った停止ログを出さないようにしています。


## PWA（ホーム画面への追加）

- アプリ名：シュナプセン
- アイコン：赤茶色の背景に2枚のカードとダイヤ。192px・512pxのPNGとiPhone用180pxを同梱。
- 起動方法：`standalone`（対応環境では通常のアドレスバーを表示しない独立画面）。
- 起動URL・アプリ識別子・対象範囲：マニフェストと同じディレクトリ。サブディレクトリへの配置にも対応。
- 画面の向きは固定しません。

PCでの確認は簡易サーバーを起動し、`http://localhost:8000` をChromeで開きます。
開発者ツールのApplication → Manifestで名前・アイコン・起動URLを確認できます。
Chromeのインストールメニューから追加後、アイコンから起動して独立画面になることを確認してください。

スマートフォンでのインストール検証にはHTTPSでの公開が必要です。
同じWi-FiのPCへHTTPで接続する方法は画面確認用で、PWAのインストール検証には使えません。
iPhoneはSafariの共有メニューから「ホーム画面に追加」、AndroidはChromeのインストールメニューを使います。
メニュー名や表示条件はOS・ブラウザによって異なります。

Service Workerによるオフライン動作、途中のゲームの保存は含みません。
再読み込み・アプリの再起動時には新しい試合になります。
マニフェストやアイコンを変更した後、OSによっては反映まで時間がかかる場合があります。

### ホーム画面への追加ボタン

画面右上の四角い＋ボタンを押すと、iOSではSafariの追加手順を表示します。
Android・PCの対応ブラウザでは「インストールしますか？」のOKからブラウザ標準の確認画面へ進みます。
標準の確認画面でもインストールの承認が必要です。
Android・PCのボタンは `beforeinstallprompt` を受信した場合のみ表示します。
インストール済み・非対応・インストール条件未成立の場合には表示しません。
アプリとして起動中、またはインストール完了を検知した場合も非表示にします。
ブラウザから端末全体のインストール状況を常に取得できるわけではありません。
キャンセル後はブラウザが再びインストール可能イベントを通知した時点で再表示されます。
検証：`node test-install.js`（iOS/iPadOS・確認/取消・完了・独立起動・失敗をモック）。
